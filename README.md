# Анализ поступления

Веб-приложение для кейса МПОШ «Анализ поступления».

## Что реализовано

- Генерация 16 конкурсных списков (4 дня x 4 ОП): `ПМ`, `ИВТ`, `ИТСС`, `ИБ`.
- Структура записи абитуриента: `ID`, согласие, приоритет, баллы, сумма.
- Загрузка/обновление списков в локальную БД (`IndexedDB`) для выбранного дня.
- Визуализация:
  - списки по ОП,
  - единый список с каскадом приоритетов,
  - сортировка, фильтрация, поиск по ID.
- Расчет проходного балла с учетом:
  - только абитуриентов с согласием,
  - приоритетов заявлений,
  - ограничений по местам (`40/50/30/20`).
- Формирование PDF-отчета:
  - дата/время,
  - проходные баллы,
  - график динамики за 4 дня,
  - списки зачисленных (4 ОП),
  - статистика по приоритетам заявлений/зачислений.
- Импорт конкурсных списков из CSV.

## Примечание

Валидация по количествам и пересечениям выводится в консоль браузера после генерации.
